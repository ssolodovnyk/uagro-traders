# ТЗ: агент пошуку зернотрейдерів «з місця» для uagro.trade

Статус: **затверджено** 2026-11-21.

## 1. Ціль і результат

**Ціль:** щоранку автоматично знаходити нові оголошення зернотрейдерів, які **купують урожай з місця** (з господарства), щоб власник швидко виходив на них і підключав до платформи uagro.trade. Замінює 1–2 години ручного гортання сайтів.

**Результат:**
- **Публічна сторінка** на GitHub Pages, зручна з телефона:
  - дві вкладки: **«З місця»** і **«Неясно — перевірити»**;
  - сортування за датою оголошення, найновіші зверху;
  - прості фільтри за ціною і обсягом.
- **Картка оголошення:**
  - культура;
  - ціна (грн/т або $/т, як в оголошенні);
  - обсяг (т);
  - область і район;
  - умови («з місця» / «неясно»);
  - назва компанії-трейдера (якщо вказана);
  - дата оголошення;
  - сайт-джерело;
  - посилання на оригінал.
- **Позначки:**
  - **«нове сьогодні»**;
  - **«не турбувати»**, коли трейдер пише «посередникам не турбувати», «тільки від виробника» тощо.
- **Статуси** (ставить лише власник): «подзвонив», «не цікаво», «взяв у роботу».
- **Без імен, телефонів, email, месенджерів.** Тільки назва компанії і посилання на оригінал.
- **Блок стану джерел** угорі сторінки. Якщо сайт не відкрився, там це написано.
- **Telegram-повідомлення** після кожного запуску. Приклад: «Сьогодні 12 нових: 9 з місця, 3 неясні. Не відкрився: clunya.com» + посилання на сторінку.

## 2. Де живе агент і чому

## 3. Як працює, по кроках

1. **8:00 за Києвом** GitHub Actions запускає агента (запуск може зсунутися на 5–30 хв — так працює GitHub).
2. Агент відкриває розділи **закупівлі** по всій Україні, всі польові культури:
   - https://agrotender.com.ua/board
   - https://agro-ukraine.com/
   - https://clunya.com/orders/page/1
   - https://agrorynok.com.ua/bbs/
3. Якщо сайт не відкрився, агент записує «не відкрився» з причиною і йде далі.
4. Класифікація оголошення:
   - ознаки «з місця», «самовивіз», «EXW», «FCA», «свій транспорт», «заберемо з господарства» → **«З місця»**;
   - ознаки «CPT», «з доставкою», «на елеватор», «у порт», «на завод» → **відкинути**;
   - жодних ознак → **«Неясно — перевірити»**.
5. Агент шукає позначку «не турбувати».
6. Агент прибирає дублі:
   - звіряє зі списком уже показаних;
   - ловить те саме оголошення на різних сайтах (за трейдером, культурою, ціною, датою).
7. Агент видаляє з тексту імена й контакти.
8. Агент оновлює сторінку на GitHub Pages і список «вже показаних».
9. Агент надсилає підсумок у Telegram.

**Статуси** зберігаються в браузері телефона власника. Є кнопка «Зберегти копію статусів у файл».

## 4. Доступи й ключі

- **Акаунт GitHub** (безкоштовний) і репозиторій для агента, сторінки та списку «вже показаних».
- **Токен Telegram-бота** (від @BotFather) і **chat ID** власника.

**Зберігання ключів:** лише в секретах репозиторію GitHub (Settings → Secrets and variables → Actions): `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Задає їх власник. Ніколи в чаті і ніколи у файлах проєкту.

## 5. Ризики і як їх уникнути

| Ризик | Захист |
|---|---|
| Сайт змінив вигляд або блокує | Позначка «не відкрився» на сторінці й у Telegram. Далі виправлення агента |
| CPT потрапило в «з місця» або навпаки | Тиждень паралельної перевірки, уточнення слів-ознак |
| Контакти на публічній сторінці | Окремий крок очищення + заборона в правилах |
| Дублі між сайтами | Порівняння за трейдером, культурою, ціною, датою |
| Втрата статусів | Кнопка резервної копії |
| Витік токена Telegram | Токен лише в секретних змінних. За потреби новий у @BotFather |
| Правила сайтів-джерел | Лише читання публічних сторінок раз на день, без реєстрації і без обходу захисту |

## 6. Заборонено без дозволу власника

- Реєструватися на сайтах-джерелах або щось там публікувати.
- Писати чи дзвонити трейдерам, відповідати на оголошення.
- Показувати на сторінці імена, телефони, email, месенджери.
- Обходити капчі чи блокування.
- Змінювати сайт uagro.trade.
- Додавати нові джерела або змінювати правила відбору.
- Надсилати в Telegram щось, крім ранкового підсумку.
- Видаляти історію вже показаних оголошень.

## 7. Як перевірити роботу

- **Пробний запуск** при побудові: ручний запуск, власник переглядає сторінку і повідомлення.
- **Перші 5 ранків:** власник паралельно переглядає сайти сам і повідомляє про розбіжності, правила уточнюються.
- **Щодня:** Telegram-повідомлення прийшло, на сторінці видно стан кожного сайту.
