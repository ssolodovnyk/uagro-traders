# Агент пошуку зернотрейдерів «з місця» (uagro.trade)

Повне технічне завдання: [ТЗ.md](ТЗ.md). Якщо ці правила і ТЗ розходяться, питати власника.

## Як спілкуватися з власником
- Власник не технічна людина. Пояснювати простою мовою, українською.
- Якщо агенту бракує даних, допомогти власнику створити файл із ними.
- Ключі й токени ніколи не просити в чат. Підказувати, де їх зберегти (секрети репозиторію GitHub: Settings → Secrets and variables → Actions).

## Що робить агент
- Щоранку о 8:00 за Києвом (GitHub Actions, файл `.github/workflows/daily.yml`) переглядає оголошення про **закупівлю** польових культур по всій Україні на:
  - agrotender.com.ua/board
  - agro-ukraine.com
  - clunya.com/orders
  - agrorynok.com.ua/bbs
- Відбір:
  - «з місця» / самовивіз / EXW / FCA → вкладка **«З місця»**;
  - CPT / доставка / на елеватор / у порт / на завод → **відкинути**;
  - без ознак → **«Неясно — перевірити»**.
- Позначки: «нове сьогодні», «не турбувати» (посередникам не турбувати / тільки від виробника).
- Без дублів: те, що вже показано, вдруге не показувати (зокрема те саме оголошення з різних сайтів).
- Результат:
  - сторінка на GitHub Pages: одна стрічка, нові зверху, фільтри за ціною й обсягом;
  - статуси власника в браузері телефона + кнопка резервної копії.
- Якщо сайт не відкрився, писати про це на сторінці й у повідомленні. Не мовчати.
- Після запуску коротке Telegram-повідомлення: скільки нових, скільки з місця й неясних, які сайти не відкрились.

## Заборонено без дозволу власника
- Реєструватися на сайтах-джерелах або щось там публікувати.
- Писати чи дзвонити трейдерам, відповідати на оголошення.
- Показувати на сторінці імена, телефони, email, месенджери. Тільки назва компанії і посилання.
- Обходити капчі чи блокування.
- Змінювати сайт uagro.trade.
- Додавати нові джерела або змінювати правила відбору.
- Надсилати в Telegram щось, крім ранкового підсумку.
- Видаляти історію вже показаних оголошень.
- Зберігати ключі у файлах проєкту.
